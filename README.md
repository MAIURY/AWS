# RELATÓRIO DE IMPLEMENTAÇÃO DE SERVIÇOS AWS

**Data:** 23 de Agosto de 2025  
**Empresa:** Abstergo Industries  
**Responsável:** [Maiury Souza Fernandes]

## Introdução

Este relatório apresenta o processo de implementação de ferramentas na empresa Abstergo Industries, realizado por [Maiury Souza Fernandes]. O objetivo do projeto foi elencar 3 serviços AWS, com a finalidade de realizar diminuição de custos imediatos.

## Descrição do Projeto

O projeto de implementação de ferramentas foi dividido em 3 etapas, cada uma com seus objetivos específicos. A seguir, serão descritas as etapas do projeto:

### Etapa 1: AWS Cost Explorer
- **Foco da ferramenta:** Análise detalhada e otimização de custos
- **Descrição de caso de uso:** Implementação para monitoramento contínuo dos gastos com AWS, identificação de recursos subutilizados e recomendações personalizadas para economia através de Reserved Instances e Savings Plans.

### Etapa 2: AWS Auto Scaling
- **Foco da ferramenta:** Escalonamento automático de recursos
- **Descrição de caso de uso:** Configuração de políticas de auto scaling para ajustar automaticamente a capacidade de instâncias EC2 conforme a demanda, garantindo desempenho otimizado e reduzindo custos com recursos ociosos.

### Etapa 3: Amazon S3 Intelligent-Tiering
- **Foco da ferramenta:** Armazenamento de dados com otimização de custos automática
- **Descrição de caso de uso:** Migração de dados para camadas de armazenamento inteligente que automaticamente move objetos entre tiers baseado nos padrões de acesso, reduzindo custos de armazenamento sem impacto no desempenho.

## Conclusão

A implementação de ferramentas na empresa Abstergo Industries tem como esperado a redução de custos, maior visibilidade financeira e otimização automática de recursos, o que aumentará a eficiência e a produtividade da empresa. Recomenda-se a continuidade da utilização das ferramentas implementadas e a busca por novas tecnologias que possam melhorar ainda mais os processos da empresa.
